# ULTRON MOBILE
Native Android prototype built with Kotlin and Jetpack Compose.

## Current release
v1.0.0-alpha.1 — HUD, chat placeholder, memory placeholder, settings placeholder.

## Build
GitHub Actions → Android Debug APK → Artifacts. The workflow builds an unsigned-for-release debug APK signed with the Android debug key.

## Roadmap
- alpha.2: Gemini integration and user-provided API key
- alpha.3: Android speech recognition and robotic TTS
- alpha.4: Cerebro local memory and tool registry

This is an independent Android adaptation inspired by AbuZar-Ansarii/Ultron. No original source code is included in this initial scaffold.
